# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed
- Phone: the Why Binder Diver heading and its text no longer sit in two crowded columns (they stack), and headings break into even lines across the app (`text-wrap: balance`). The Walkthrough's Questions heading is larger than the questions under it, as are other section headings on the text pages.
- The tour's lit-up box stays on its target on a phone. It was read once, so when card data or a banner arrived and moved the page, the box was left behind; it is now followed every frame. The Start store dive tip also pointed at a wrapper around the button (a text-height strip); it points at the button itself.
- A card's picture now matches the print it is shown as. Before, the picture was always the card's newest print, while the set, number and price were the print the binder is predicted to hold: a Giada borderless picture sat beside the $0.55 regular print. The store dive (gallery and table), the list review rows and card detail now show the picture of the predicted print, with its tag after the set and number (Borderless, Showcase, Extended art, Full art or Promo) when it is not the usual look. If that picture cannot load, the card's usual picture is shown. Lists still do not record which print a player owns, so there is no keep-my-print choice yet.
- The phone QR code no longer disappears when you are trying a sample deck: a sample deck now goes into the phone link like any other list. The code is bigger and drawn as rounded blocks instead of the plain pixel grid; how fine the grid is still depends on how many cards are in the link.

A failed download fails the build, so a Scryfall outage keeps the last deploy. Names it does not know, or everything while the data files are unavailable, go to the live Scryfall API as before. Until the daily refresh (next step) publishes data files, the app keeps using the live API.
- Faster first load of a list's card data: printings are fetched four cards at a time instead of one (request starts are still spaced 100 ms apart, so Scryfall's rate limit holds), and basic lands no longer fetch their hundreds of printings. - Scryfall requests no longer send a custom `User-Agent` header: Scryfall's docs require browser code to keep the browser's own, and a custom one forced a CORS preflight on every request. The client's `userAgent` option is removed.

- `resumableLookup`: a name lookup that saves progress after every batch, so an interrupted import resumes with only the missing names.
- Storage seam in `src/storage`: an `AppStorage` interface with an IndexedDB implementation (via `idb`) and an in-memory one. `createStorage` falls back to memory when IndexedDB is unavailable, and `persistent` tells the UI which one it got. Both pass the same contract tests.
- Decklist parser in `src/core/parse`: `parseDecklist` reads Moxfield, Archidekt, EDHREC and MTGO text (counts, set codes, collector numbers, foil tags, `#tags`, headers, sideboard and maybeboard sections) and `combineEntries` merges duplicate lines under the section toggles.
- Engine: `reopenStop` brings a finished stop's unfound cards back and keeps the frozen stop order. `Plan` now carries `order` and `left` to support it.
- Engine: `pullVerdict` labels plan stops "Worth a pull", "Buy online" or "Show staff" from `PullSettings` (default 2 copies or $10, in `pullSettings.ts`). It never changes routing.
- Routing engine in `src/core/engine`, copied from `reference/engine`: per-printing routing, scoring, plan building and Finish stop. `WEIGHTS` and `V1_STORE` are in their own modules. 29 Vitest checks, ported one for one from the reference tests, plus the missing 21c.
- Project scaffold: Vite, React, TypeScript (strict), Vitest, ESLint, GitHub Actions CI (lint, test, build).
- Design tokens in one place with a Magic theme, shared breakpoints, feature flags (v2 and v3 off) and a copy module.
- Footer on every page with the verbatim Fan Content disclaimer and the Scryfall credit, with a test that guards the wording.
- Cloudflare Pages config (SPA fallback and headers), MIT license, build plan in `docs/PLAN.md`.
